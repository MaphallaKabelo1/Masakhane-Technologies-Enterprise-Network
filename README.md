# Masakhane Technologies Enterprise Network

## Project Overview

This project presents the design and implementation of a secure, scalable, and reliable enterprise network for **Masakhane Technologies (Pty) Ltd**, a fictional small-to-medium-sized IT company with approximately **40 employees**.

The network was designed and implemented using **Cisco Packet Tracer** and follows industry best practices for enterprise networking. It provides secure wired and wireless connectivity, departmental network segmentation using VLANs, structured IPv4 addressing, Inter-VLAN routing, centralised network services, and multiple security mechanisms.

---

## Project Objectives

- Design a secure enterprise network.
- Implement departmental VLAN segmentation.
- Configure structured IPv4 addressing.
- Implement Inter-VLAN routing.
- Configure DHCP and DNS services.
- Implement secure wired and wireless networking.
- Configure enterprise network security.
- Simulate and validate the network using Cisco Packet Tracer.
